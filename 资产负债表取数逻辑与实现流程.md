
          
## 资产负债表取数逻辑与实现流程

### 一、数据源：`account_balance` 表

资产负债表的数据来源是 **`account_balance`**（账簿余额表），核心字段：

| 字段 | 说明 |
|------|------|
| `account_id` | 账套ID |
| `period_id` | 会计期间ID |
| `account_subject_id` | 会计科目ID |
| `ending_dr_func` | **期末借方余额**（函数计算后，本位币） |
| `ending_cr_func` | **期末贷方余额**（函数计算后，本位币） |
| `beginning_dr_func` | **期初借方余额**（函数计算后，本位币） |
| `beginning_cr_func` | **期初贷方余额**（函数计算后，本位币） |
| `balance_type` | 余额类型（0=暂存, 1=已审批） |

### 二、取数口径

根据代码注释（[BalanceSheetReportService.php:L57-63](file:///home/wwwroot/adc-finance/app/Service/BalanceSheetReportService.php#L57-63)）：

| 取数类型 | 数据来源 | 说明 |
|----------|----------|------|
| **期末余额** | `ending_dr_func` / `ending_cr_func` | 查询期间相关科目的期末余额（本位币、已审核账） |
| **年初余额** | `beginning_dr_func` / `beginning_cr_func` | 查询期间所在年份第1期相关科目的年初余额 |
| **科目汇总** | 自身 + 全部子科目 | 按科目层级汇总后再计算净额 |
| **净额计算** | `loan_direction` 决定 | 借方科目：借 - 贷；贷方科目：贷 - 借 |

```php
// BalanceSheetReportService::resolveQueryPeriod()
private function resolveQueryPeriod(int $accountId, array $params): AccountPeriod
{
    $periodUid = trim((string) ($params['period_uid'] ?? ''));
    
    if ($periodUid !== '') {
        // 指定期间
        $period = AccountPeriod::query()
            ->whereUuid('uid', $periodUid)
            ->whereHas('calendar', static function ($q) use ($accountId): void {
                $q->where('account_id', $accountId);
            })
            ->first();
    } else {
        // 默认取当前期间（is_current=1）
        $period = AccountPeriod::query()
            ->isCurrent()
            ->whereHas('calendar', static function ($q) use ($accountId): void {
                $q->where('account_id', $accountId);
            })
            ->first();
    }
    
    return $period;
}
```

#### 3. 科目后代映射构建

[buildSubjectDescendantMap()](file:///home/wwwroot/adc-finance/app/Service/BalanceSheetReportService.php#L1064-1112)：

```php
private function buildSubjectDescendantMap(int $accountId, array $codes): array
{
    // 查询所有科目
    $subjects = AccountSubject::query()
        ->where('account_id', $accountId)
        ->get(['id', 'parent_id', 'full_segment_code', 'loan_direction']);
    
    // 构建树结构
    $childrenByParent = [];
    $idByCode = [];
    $dirById = [];
    foreach ($subjects as $subject) {
        $childrenByParent[(int) ($subject->parent_id ?? 0)][] = (int) $subject->id;
        $idByCode[(string) $subject->full_segment_code] = (int) $subject->id;
        $dirById[(int) $subject->id] = (int) $subject->loan_direction;
    }
    
    // BFS 遍历获取所有后代
    foreach ($codes as $code) {
        $rootId = $idByCode[$code] ?? 0;
        $ids = [$rootId];
        $frontier = [$rootId];
        while ($frontier !== []) {
            $next = [];
            foreach ($frontier as $pid) {
                foreach ($childrenByParent[$pid] ?? [] as $cid) {
                    $ids[] = $cid;
                    $next[] = $cid;
                }
            }
            $frontier = $next;
        }
        $idsByCode[$code] = array_values(array_unique($ids));
        $dirByCode[$code] = $dirById[$rootId] ?? 0;
    }
    
    return [$idsByCode, $dirByCode];
}
```

**映射结构**：
- `$idsByCode['1001']` = `[1, 2, 3]`（科目代码 '1001' 及其子科目 ID 列表）
- `$dirByCode['1001']` = `1`（借贷方向：1=借方，2=贷方）

#### 4. 余额数据加载

[loadBalanceMap()](file:///home/wwwroot/adc-finance/app/Service/BalanceSheetReportService.php#L1121-1151)：

```php
private function loadBalanceMap(int $accountId, array $subjectIds, array $periodIds): array
{
    $rows = AccountBalance::query()
        ->where('account_id', $accountId)
        ->where('balance_type', BalanceType::APPROVED)  // 仅取已审批余额
        ->whereIn('period_id', $periodIds)
        ->whereIn('account_subject_id', $subjectIds)
        ->selectRaw(
            'period_id, account_subject_id,'
            . ' SUM(ending_dr_func) AS e_dr, SUM(ending_cr_func) AS e_cr,'
            . ' SUM(beginning_dr_func) AS b_dr, SUM(beginning_cr_func) AS b_cr'
        )
        ->groupBy('period_id', 'account_subject_id')
        ->get();
    
    // 构建三维映射：period_id → subject_id → {e_dr, e_cr, b_dr, b_cr}
    $map = [];
    foreach ($rows as $row) {
        $map[(int) $row->period_id][(int) $row->account_subject_id] = [
            'e_dr' => (float) $row->e_dr,
            'e_cr' => (float) $row->e_cr,
            'b_dr' => (float) $row->b_dr,
            'b_cr' => (float) $row->b_cr,
        ];
    }
    
    return $map;
}
```

```php
private function netByDirection(float $dr, float $cr, int $loanDirection): float
{
    // 贷方科目：贷 - 借；借方/无方向：借 - 贷
    return LoanDirectionI18n::isCredit($loanDirection) ? $cr - $dr : $dr - $cr;
```

#### 6. 行值计算

[computeLineValues()](file:///home/wwwroot/adc-finance/app/Service/BalanceSheetReportService.php#L1160-1204)：

```php
private function computeLineValues(array $itemsByLine, string $mode, callable $subjectResolver): array
{
    $memo = [];  // 缓存已计算的行值
    $stack = []; // 循环引用保护
    
    $evalLine = function (int $line) use (&$evalLine, &$memo, &$stack, $itemsByLine, $mode, $subjectResolver): float {
        // 1. 检查缓存
        if (array_key_exists($line, $memo)) {
            return $memo[$line];
        }
        // 2. 循环引用检测
        if (isset($stack[$line])) {
            return 0.0;
        }
        
        $item = $itemsByLine[$line] ?? null;
        $ast = $mode === 'beginning'
            ? $item->parsed_formula_beginning_balance
            : $item->parsed_formula_ending_balance;
        
        // 3. 标记正在计算
        $stack[$line] = true;
        
        // 4. 构建解析器
        $resolver = static function (array $node) use ($evalLine, $subjectResolver, $mode): float {
            $type = $node['type'] ?? '';
            if ($type === 'line') {
                return $evalLine((int) ($node['line'] ?? 0)); // 引用其他行
            }
            if ($type === 'subject') {
                return $subjectResolver($node, $mode); // 引用科目
            }
            return 0.0;
        };
        
        // 5. 公式求值
        $value = (new BalanceSheetFormulaEvaluator($resolver))->evaluate(is_array($ast) ? $ast : null);
        
        // 6. 清除标记
        unset($stack[$line]);
        
        return $memo[$line] = $value;
    };
    
    // 计算所有行
    foreach (array_keys($itemsByLine) as $line) {
        $evalLine((int) $line);
    }
    
    return $memo;
}
```

```php
private function buildBalanceCheck(array $items, array $endingByLine, array $beginningByLine): array
{
    // 获取资产总计行和负债权益总计行
    $assetTotalLine = $this->resolveSectionTotalLine($items, 1);      // section_type=1（资产）
    $liabEquityTotalLine = $this->resolveSectionTotalLine($items, 2); // section_type=2（负债权益）
    
    // 比较期末余额
    $endAsset = $endingByLine[$assetTotalLine] ?? 0.0;
    $endLiab = $endingByLine[$liabEquityTotalLine] ?? 0.0;
    $endBalanced = abs($endAsset - $endLiab) < 0.005;
    
    // 比较年初余额
    $begAsset = $beginningByLine[$assetTotalLine] ?? 0.0;
    $begLiab = $beginningByLine[$liabEquityTotalLine] ?? 0.0;
    $begBalanced = abs($begAsset - $begLiab) < 0.005;
    
    return [
        'is_balanced' => $endBalanced && $begBalanced,
        'ending' => [...],
        'beginning' => [...],
    ];
}
```

### 六、与利润表的区别

| 维度 | 资产负债表 | 利润表 |
|------|-----------|--------|
| **取数类型** | 余额（期末/年初） | 发生额（本期/累计） |
| **数据源字段** | `ending_*`, `beginning_*` | `current_dr_func`, `current_cr_func` |
| **公式模式** | `ending` / `beginning` | `current_period` / `current_year` / `previous_year` |
| **平衡校验** | 资产 = 负债 + 权益 | 无 |
| **报表结构** | 左右两栏（资产 / 负债权益） | 单栏 |
