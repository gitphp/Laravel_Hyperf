         
## 账目结算校验规则引擎架构解析

### 整体架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    SettleCheckExecuteService                    │
│              结账校验执行服务（编排整个校验流程）                   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    SettleCheckRuleEngine                        │
│          规则引擎：读取 condition_expr 并安全求值                │
└─────────────────────────────────────────────────────────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
┌───────────────┐    ┌───────────────┐    ┌───────────────┐
│ 规则配置表    │    │ 预警配置表    │    │ 表达式函数    │
│ condition_expr│    │ condition_expr│    │ Provider      │
└───────────────┘    └───────────────┘    └───────────────┘
                              │                     │
                              ▼                     ▼
                    ┌───────────────┐    ┌───────────────┐
                    │ SettleCheck   │    │ SettleCheck   │
                    │ RuleKey       │    │ Functions     │
                    │ (默认表达式)   │    │ (校验逻辑)    │
                    └───────────────┘    └───────────────┘
```

### 1. 表达式定义位置

#### 默认表达式（代码层面）

**文件**：`app/Constants/SettleCheck/SettleCheckRuleKey.php:52-71`

```php
public static function defaultExpressions(): array
{
    return [
        // 必要基础核查
        self::VOUCHER_SERIAL_CONTINUOUS => 'isVoucherNumbersContinuous(account_id, period_id)',
        self::FOREIGN_CURRENCY_PL => 'hasForeignCurrencyExchangeDone(account_id, period_id)',
        self::SETTLEMENT_BALANCE => 'isSettlementBalanceMatched(account_id, period_id)',
        self::PL_ACCOUNT_ZERO => 'areProfitLossAccountsZero(account_id, period_id)',
        self::BASIC_TABLE_ARTICULATION => 'isBasicTableArticulated(account_id, period_id)',
        
        // 无再生资源
        self::STAT_LOG_TABLE => 'hasNoUnsettledStatLogEntries(account_id, period_id)',
        self::BUSINESS_DOC_LIST => 'hasNoUnprocessedBusinessDocuments(account_id, period_id)',
        // ... 更多规则
    ];
}
```

#### 自定义表达式（数据库层面）

通过 `settle_check_rule_config` 表的 `condition_expr` 字段存储，优先级高于默认表达式：

```php
// SettleCheckRuleEngine::resolveRuleExpression()
public function resolveRuleExpression(array $rule): string
{
    $expr = trim((string) ($rule['condition_expr'] ?? ''));
    if ($expr !== '') {
        return $expr;  // 优先使用数据库配置的表达式
    }
    // 否则使用默认表达式
    return SettleCheckRuleKey::defaultExpressions()[$ruleKey] ?? 'true';
}
```

### 2. 可调用的表达式函数

所有函数在 **`SettleCheckFunctions.php`** 中定义，通过 **`SettleCheckExpressionFunctionProvider.php`** 注册到 Symfony ExpressionLanguage：

| 函数名 | 参数 | 功能说明 |
|--------|------|----------|
| `isVoucherNumbersContinuous` | `account_id, period_id` | 凭证字号流水号是否连续无断号 |
| `hasForeignCurrencyExchangeDone` | `account_id, period_id` | 外币科目是否已完成期末调汇 |
| `isSettlementBalanceMatched` | `account_id, period_id` | 科目余额勾稽（期初+本期=期末） |
| `areProfitLossAccountsZero` | `account_id, period_id` | 损益类科目期末余额是否为零 |
| `isBasicTableArticulated` | `account_id, period_id` | 资产负债表勾稽（资产=负债+权益） |
| `hasNoUnsettledStatLogEntries` | `account_id, period_id` | 无未执行完毕的结算单 |
| `hasNoUnprocessedBusinessDocuments` | `account_id, period_id` | 无草稿/待审核业务单据 |
| `hasNoUnmappedSettlementVouchers` | `account_id, period_id` | 结算单均已生成凭证 |
| `hasNoUnmappedReceiptVouchers` | `account_id, period_id` | 收款单均已生成凭证 |
| `hasNoUnmappedInvoiceVouchers` | `account_id, period_id` | 发票相关单据均已生成凭证 |
| `hasNoUnboundFundAccounts` | `account_id` | 资金账户科目均已绑定资金账户 |
| `hasNoUnboundSpecialProjectAccounts` | `account_id` | 专项项目科目均已绑定结算主体 |
| `hasNoUnboundMinimalistAccounts` | `account_id` | 极简账户均已配置账户形态 |
| `compareDataTargets` | `account_id, period_id, targetAIds, targetBId, operator, threshold` | 数据比较预警 |

### 4. 执行流程

```
1. 结账时调用 SettleCheckExecuteService::executeForRun()
                    │
                    ▼
2. 获取启用的校验规则（从 settle_check_rule_config 表）
                    │
                    ▼
3. 创建 SettleCheckContext（封装 account_id, period_id 等）
                    │
                    ▼
4. 遍历每条规则，调用 SettleCheckRuleEngine::evaluateRule()
                    │
                    ▼
5. 解析表达式：优先使用数据库的 condition_expr，否则用默认表达式
                    │
                    ▼
6. Symfony ExpressionLanguage 求值，调用对应的校验函数
                    │
                    ▼
7. 根据返回的布尔值判断通过/失败，并记录到 PeriodCloseCheckResult
```

### 5. 使用示例

#### 自定义表达式示例

在 `settle_check_rule_config` 表的 `condition_expr` 字段中设置：

```sql
-- 示例1：组合多个校验条件
isVoucherNumbersContinuous(account_id, period_id) and areProfitLossAccountsZero(account_id, period_id)

-- 示例2：使用逻辑运算符
hasForeignCurrencyExchangeDone(account_id, period_id) or account_id == 123

-- 示例3：数据比较预警（自动生成）
compareDataTargets(account_id, period_id, "1,2,3", 4, ">=", 30)
```

#### 新增自定义校验规则

1. 在 `SettleCheckRuleKey.php` 中定义规则标识和默认表达式
2. 在 `SettleCheckFunctions.php` 中实现校验逻辑
3. 在 `SettleCheckExpressionFunctionProvider.php` 中注册函数
4. 在数据库中插入规则配置（或通过 API 创建）
